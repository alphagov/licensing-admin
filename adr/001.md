# ADR-001

## Title 
Use Playwright and Testcontainers to test Admin App

## Status
Accepted

## Context
- We need to build and validate the correct operation of the new Licensify Admin App
- To validate correct operation, we need to integrate the Licensify Admin App with existing third-party systems
- We want to get as much confidence out of our tests as possible for the least effort
- The Licensify Admin App is UI-driven for the most part

## Decision
The team has decided to use [acceptance test driven development](https://agilealliance.org/glossary/atdd/) to validate
the correct functionality of the Licensify Admin App. Accordingly, the team has decided to use 

- [Playwright](https://playwright.dev/) to allow for UI-driven testing (the UI is the primary interface for Licensify
Admin App users)
- [Testcontainers](https://testcontainers.com/) to allow us to test against as-close-to-production-as-possible third-party 
system dependencies while abstracting away the boilerplate set-up and tear-down of these dependencies.

## Consequences

### Positives
- Allows us to have high test fidelity relative to production
- High code coverage for less test code

### Negatives
- Arguably slower with respect to test suite execution times than lower-level testing styles
- Requires a container orchestration platform to be installed in order to run the test suite
