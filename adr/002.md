# ADR-001

## Title 
Mock out [GOV.UK Signon](https://github.com/alphagov/signon) for Testing

## Status
Accepted

## Context
- The current and new Licensing Admin application is designed to be used by UK Civil Servants
- The current Licensing Admin application written in Scala uses GOV.UK Signon to authenticate and authorise UK Civil Servants
- We need to ensure that the new Licensing Admin application can integrate correctly with GOV.UK Signon to retain functional parity
with the current Licensing Admin application
- GOV.UK Signon is a mature product therefore, there is little chance of the API endpoints of interest changing significantly

## Decision
The team has decided to mock out GOV.UK Signon using [MockServer](https://www.mock-server.com/) with strict adherence to the 
relevant endpoint contracts that we are to integrate with (see [here](https://docs.publishing.service.gov.uk/repos/signon/oauth.html)).
This allows us to bypass setting up GOV.UK Signon ourselves, and focus on the essential aspects of the integration which are:

- To send back an appropriate auth code response via JSON
- To send back an appropriate access token response via JSON
- To send back appopriate user details via JSON

## Consequences

### Positives
- Allows us to set up a working integration of GOV.UK Signon quickly
- Avoids automated navigation of a third-party UI, resulting in a less-britlle test suite
- Lightweight and fast GOV.UK Signon user set-up
- Less computationally expensive to stand-up a GOV.UK Signon integration

### Negatives
- We have to maintain REST API contract parity with a third-party who will not provide advanced notice of changes
- We can't be fully assured that what we've built will work with GOV.UK Signon in reality
